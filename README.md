# 正義實踐（PWA）

可安裝到手機、可離線使用的網頁應用程式。所有資料只存在使用者手機的瀏覽器中，不會傳送到任何伺服器。

## 檔案
- `index.html`、`styles.css`、`app.js`：介面與評分邏輯
- `data.js`：評分維度與 18 項策略資料庫（要新增或修改策略，改這個檔案）
- `plans.js`：每項策略的分階段行動計劃（做什麼、怎樣做、完成標準）
- `region.js`：地區選擇，把公開數據換算成 1–5 分
- `data/region-data.json`：世界銀行開放數據快照，由 `scripts/fetch-data.mjs` 產生
- `.github/workflows/update-data.yml`：每月 1 日自動更新公開數據
- `sw.js`：離線快取（每次更新內容，請把 `CACHE` 版本號加一）
- `manifest.webmanifest`、`icons/`：安裝到主畫面所需

## 評分方式
- 選擇地區後：每個世界銀行指標按全球各國排名換算百分位，再分成五等份（1–5 分）。只有替代指標的因素（如薪資）不自動套用。社會流動與住房負擔沒有可跨國比較的 API 數據，需要手動評估。手機端只讀取同一網站上的數據檔，不會向世界銀行或其他伺服器傳送使用者選擇。
- 不正義指數：7 項地區自評（1–5 分）的平均值換算為 0–100。屬主觀評估，不是客觀測量。
- 策略相關度：策略對應的地區因素分數 × 權重，加上個人處境的加分（如：你是租客 → 租戶聯會加分）。
- 推薦程度：策略的基本風險（言論受限地區另加）、你的儲蓄與供養負擔，與你自填的風險承受度比較。
- 效果評估：只提供運作機制、「人數與效果」的關係型態，以及可代入使用者自行查證數據的公式。不內置任何未查證的數字。

## 本機測試
在此資料夾執行 `python3 -m http.server 8000`，再開啟 http://localhost:8000 。

## 安裝到手機
需要放在 HTTPS 網址上（例如 GitHub Pages 或 Netlify）。之後：
- iPhone：Safari →「分享」→「加入主畫面」
- Android：Chrome → 選單 →「安裝應用程式」
